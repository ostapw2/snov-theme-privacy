Snov Theme — Privacy Policy

Effective date: 18 August 2026
Extension: Snov Theme (Chrome Web Store)
Contact: o.shtai@snov.io

Snov Theme has no accounts, no analytics, no tracking, no advertising and no remote code. It does not sell or share personal data with anyone. Everything the extension remembers is kept in your own browser. The single exception is the optional Team Comments feature, which — only after you switch it on and paste in your own team endpoint — sends the comments you write to that endpoint of yours. Details below.

What the extension stores, and where

All of the following is written to chrome.storage.local on your own device and never leaves the browser:

  • the dark-theme on/off state and the individual page-feature switches;
  • style edits made with the built-in visual editor (per-site overrides, classes, design tokens, moved or duplicated elements, text edits, guides);
  • images or icons you upload to replace one on a page;
  • the campaign-flow screenshot the floating campaign card shows (captured from your own visible tab and displayed back to you in the same tab);
  • the editor's undo history (chrome.storage.session, dropped when Chrome closes).

Uninstalling the extension deletes all of it. “Reset site” inside the extension clears it for one site.

Where the extension is allowed to run

https://app.snov.io/* and https://preprod.snov.io/* only. The extension has no access to any other website, and it reads nothing from any other tab.

Network requests

  1. To Snov.io itself. Some page enhancements read data the Snov.io page has already loaded from its own API (for example the current search-results page, so that a row can show which list it belongs to). These are ordinary same-site requests made with your existing Snov.io session, exactly as the page's own code makes them. Nothing is sent to us or to any third party, and no response is stored beyond the tab's own memory.
  2. To your team's own endpoint — only if you enable Team Comments. This optional feature is off and unconfigured out of the box: it does nothing until you paste in the URL of a Google Apps Script web app that you or your team deploy and control. Once you do, the comments you write are sent there so your teammates can read them. What is sent: the comment text, the display name you type for yourself, a timestamp, the site host and page path the comment is pinned to, and a CSS selector plus a short text snippet identifying the element it points at. The destination is your own Google Workspace deployment — the author of the extension operates no server and receives none of it. Clearing the endpoint in the extension's settings stops all of it.

There are no other network requests. No analytics endpoint, no error reporting, no update pings of our own.

What the extension never does

  • It does not collect or transmit personally identifiable information, authentication information, financial information, health information, personal communications, location, browsing history or user activity.
  • It does not read or exfiltrate the contents of Snov.io pages, your prospect data, your emails or your credentials.
  • It does not sell or transfer any data to third parties, and it does not use any data for advertising, credit assessment or lending.
  • It does not use any data for any purpose unrelated to restyling and enhancing Snov.io pages.
  • It loads no remote code: every line it runs ships inside the published package.

Children

The extension is a workplace tool for Snov.io users and is not directed at children.

Changes

If this policy changes, the new version is published at this same URL with a new effective date.
