Snov Theme — Privacy Policy

Effective date: 18 August 2026
Extension: Snov Theme (Chrome Web Store)
Contact: o.shtai@snov.io

Snov Theme collects nothing. No accounts, no analytics, no tracking, no advertising, no remote code, and no server of ours anywhere. The one thing it remembers — whether you have the improvements switched on — is kept in your own browser.

What the extension stores, and where

In chrome.storage.local, on your own device, and nowhere else:

  • whether the improvements are switched on (the toolbar icon toggles it);
  • the thumbnail of your own campaign flow shown on the floating progress card. It is captured from your own visible tab and displayed back to you in the same tab.

Uninstalling the extension deletes both.

Where the extension is allowed to run

https://app.snov.io/* and https://preprod.snov.io/* only. It has no access to any other website and reads nothing from any other tab.

Network requests

The extension has no server, no endpoint and no analytics. It sends nothing to us, because there is no “us” to send it to.

Some improvements read data the Snov.io page has already loaded from Snov's own API — for example the current page of search results, so that a row can show which list a prospect belongs to, or a LinkedIn handle the table does not print. Those are ordinary same-site requests, made with your existing Snov.io session, exactly as the page's own code makes them, and the responses are used to draw that page and are not stored.

What the extension never does

  • It does not collect or transmit personally identifiable information, authentication information, financial information, health information, personal communications, location, browsing history or user activity.
  • It does not read or exfiltrate your prospect data, your emails or your credentials.
  • It does not sell or transfer any data to third parties, and it uses no data for advertising, credit assessment or lending.
  • It uses nothing for any purpose unrelated to improving Snov.io pages.
  • It loads no remote code: every line it runs ships inside the published package.

Children

The extension is a workplace tool for Snov.io users and is not directed at children.

Changes

If this policy changes, the new version is published at this same URL with a new effective date.

Contact

Questions or removal requests: o.shtai@snov.io
